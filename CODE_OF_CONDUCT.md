# Code of Conduct

Vooya is committed to a welcoming, respectful, and technically honest open
source community.

## Expected behavior

- Be respectful when reviewing ideas, code, and evidence.
- Critique technical decisions without attacking the person proposing them.
- Welcome questions from contributors with different Rust, Web, and English
  experience levels.
- State uncertainty and correct mistakes openly.
- Respect privacy. Do not publish private conversations, contact details, or
  contributor evaluations without permission.
- Give credit for contributions and do not pressure volunteers into fixed time
  commitments.

## Unacceptable behavior

Harassment, discrimination, threats, sexualized attention, deliberate
intimidation, doxxing, sustained disruption, and knowingly misleading public
claims are not acceptable in project spaces.

## Enforcement

Maintainers may edit or remove comments, commits, code, issues, or other
contributions that violate these standards, and may temporarily or permanently
restrict participation when necessary.

For content hosted on GitHub, use GitHub's private reporting and abuse-reporting
features when possible. If a public issue is the only available contact path,
request a private maintainer contact without including sensitive details.

This code applies to repository discussions, pull requests, issues, community
spaces operated for Vooya, and public representation of the project.
